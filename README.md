# Портфолио — Nadia Stelmashuk

Статический сайт на [Astro](https://astro.build). Сборка и публикация автоматические:
любой push в ветку `main` пересобирает сайт и выкладывает его на GitHub Pages.

- Адрес: https://naddians.github.io/portfolio/
- Языки: английский (`/`) и сербский-латиница (`/sr/`)
- Техническое задание: [SPEC.md](SPEC.md) · анкета с контентом: [CONTENT.md](CONTENT.md)

---

## Как добавить фотографии

1. Экспортируй кадры: **JPEG, длинная сторона 2560 px, качество 85, sRGB**,
   в полях IPTC заполнены `Creator` и `Copyright`.
2. Назови файлы так:

   ```
   10-spa-2026-verstappen-eau-rouge.jpg
   20-monza-2026-pit-stop-ferrari.jpg
   ```

   - число впереди задаёт **порядок в галерее**, нумеруй с шагом 10 —
     тогда между 10 и 20 всегда можно вставить 15;
   - остальное — латиницей через дефисы, из этого автоматически собирается
     описание кадра для поисковиков (на экране оно не видно).

3. Положи файлы в нужную папку:

   ```
   src/photos/track/         галерея «Track»
   src/photos/portraits/     галерея «Portraits»
   src/photos/atmosphere/    галерея «Atmosphere»
   src/photos/hero.jpg       кадр на первый экран главной
   src/photos/about/portrait.jpg   портрет для страницы «Обо мне»
   ```

4. Отправь изменения:

   ```bash
   git add . && git commit -m "photos: Spa 2026" && git push
   ```

Через пару минут кадры на сайте. Ничего больше править не нужно: размеры,
форматы (AVIF/WebP), превью и ленивая загрузка считаются при сборке.

## Как поменять тексты

| Что | Где |
|---|---|
| Все надписи, названия галерей, meta-описания | `src/i18n/en.json` и `src/i18n/sr.json` |
| Контакты, список событий, техника, коллаборации | `src/data/site.ts` |
| Цвета, отступы, шрифт | `src/styles/global.css` |

Переименование галереи = поменять `title` в обоих JSON. Если нужно поменять и
адрес страницы (`/track/` → `/racing/`), то ещё: имя папки в `src/photos/`,
запись в `GALLERIES` (`src/data/site.ts`), ключи в обоих JSON и имена файлов
страниц в `src/pages/` и `src/pages/sr/`.

## Локальный запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:4321/portfolio/

```bash
npm run build     # собрать в dist/
npm run preview   # посмотреть собранную версию
```

## Свой домен

Когда появится домен, нужно три вещи:

1. в `astro.config.mjs` заменить `site` на `https://твойдомен` и `base` на `'/'`;
2. в `public/robots.txt` поправить адрес карты сайта;
3. добавить файл `public/CNAME` с одной строкой — доменом, и прописать DNS-записи
   у регистратора.

Переделывать ссылки внутри сайта не придётся: они строятся от этих настроек.
